• tac （catの逆さ）
	• ファイルの内容を最終行から1行目に向かって逆順（ボトムアップ）に表示します。ログファイルを一番新しい（下にある）部分から遡って見たいときや、逆順に並べ替えたいときに使います。
• rev
	• ファイルの各行の文字を1文字ずつ左右反逆（リバース）にして表示します。「abc」なら「cba」になります。文字のパズルやテストデータ作成以外で実務で使うことはほぼない超ニッチ枠です。
• nl （number lines）
	• cat -nと同じように行番号をつけて表示しますが、「本文の行だけ」「セクションごと」など、行番号の付け方を細かくカスタマイズできます。空白行を無視したり、特定の正規表現にマッチした行だけに番号を振る高機能版です。
• od （octal dump）または hexdump / xxd
	• テキストファイルの中身を16進数（Hex）や8進数、ASCIIコードの表として出力します。バイナリファイルや、改行コード（CRLFかLFか）や特殊な制御文字が混じっていないか厳密にデバッグしたい時に使います。
• fold
	• 指定した文字数（デフォルトは80文字）で自動的に改行を入れてテキストを表示します。長すぎる1行のテキストを画面幅に合わせて折り返したいときに便利です。
• paste
	• 複数ファイルの1行目同士、2行目同士をタブ区切りで横に結合して出力します。catが「縦につなぐ」のに対し、pasteは「横に並べて表示」します。
• awk '{print}' または sed ''
	• テキスト処理の王様であるawkやsedに「何も加工しない（出力するだけ）」という最小限のプログラムを渡してcat代わりにする方法です。シェルスクリプトのパイプ途中の動作確認などでよく使われます。


. 本来は「書き換え・加工」系

ファイルを編集・変換するためのコマンドですが、「何も変換しない」という条件を与えることで cat 化します。
• sed '' filename
	• もっとも有名。 ストリームエディタ（sed）に空のスクリプト（何もしない）を渡すことで、ファイルをそのままスルーさせて出力します。
• awk 1 filename
	• 条件判定を利用。 awkは 条件 {アクション} の形で動きますが、条件に 1（常に真）だけを指定し、アクションを省略すると「全行をそのままプリントする」というデフォルト挙動になります。
• tr '' '' < filename（または tr -d '' < filename）
	• 文字置換を利用。 何も置換しない、あるいは何も削除しないように実行することで、中身がそのまま標準出力に流れます。

2. 本来は「検索・フィルター」系

ファイルの一部を抽出するためのコマンドですが、「全体がマッチする条件」にすることで cat 化します。
• grep '' filename
	• 空文字を検索。 すべての行には「空文字」が含まれているため、結果としてファイル全体のすべての行がマッチして出力されます。
• grep -v 'この世に存在しない文字列' filename
	• 逆張り検索。 -v（一致しない行を表示）を使い、絶対に存在しない文字列を指定することで、すべての行を引っ掛けます。
• head -n -0 filename（または tail -n +1 filename）
	• 範囲指定の裏技。 head -n -0 は「お尻から0行を除いたすべて（＝全部）」、tail -n +1 は「1行目から最後まで（＝全部）」という意味になり、cat と化します。

3. 本来は「ファイル情報・構造の確認」系

ファイルそのものの情報を見るコマンドの応用です。
• dd if=filename
	• ブロックコピー。 本来はディスクのバックアップやイメージ作成に使いますが、入力ファイル（if）だけを指定して出力先（of）を省略すると、標準出力（画面）に中身がダンプされます。
• od -An -c filename | tr -d ' '
	• バイナリダンプ。 od で文字（-c）として出力し、アドレス表示を消し（-An）、余計なスペースを tr で詰めれば、かなり無理矢理ですがテキストが復元されます。

1. 本来は「比較・差分・パッチ」系

2つのファイルや変更点を扱うコマンドですが、「片方を空にする」または「自分自身と比較する」ことで cat 化します。
• diff --normal /dev/null filename | mine の応用（または sdiff）
	• /dev/null（空ファイル）との比較。 diff /dev/null filename を実行すると、空のファイルに対して「すべての行が追加された」という差分（行頭に > がついた状態）が出力されます。ここから sed や cut で > を削れば元のファイルになります。
• patch -o - /dev/null filename
	• 空ファイルへのパッチ適用。 本来は差分ファイルを適用するコマンドですが、パッチとして元のファイルを指定し、ベースを空にすると、結果的に中身がそのまま標準出力（-o -）に吐き出されます。

2. 本来は「並び替え・反転」系

データの順番をいじるコマンドですが、「2回通す」ことで元に戻すマニアックな手法です。
• tac filename | tac
	• 逆の逆は正。 tac はファイルを下から（行単位で逆順に）表示するコマンドです。これをパイプで2回繋ぐと、ひっくり返ったものがもう一度ひっくり返り、完全に cat と同じになります。
• rev filename | rev
	• 左右反転のコンボ。 rev は各行の「文字列を左右逆転」にするコマンドです。これも2回通すことで、文字の並びが元通りになって出力されます。

3. 本来は「圧縮・アーカイブ」系

ファイルを固めるコマンドですが、「圧縮・解凍を同時に標準出力で行う」、あるいは「非圧縮モードでアーカイブする」ことで cat 化します。
• gzip -c filename | gunzip
	• 超高速の無駄遣い。 一瞬だけメモリ（またはパイプ）上で圧縮し、それを即座に解凍して画面に出力します。bzip2 や xz でも同じことができます。
• tar -O -cf - filename | tar -xf -
	• アーカイブの空中分解。 tar でファイルをアーカイブ化し、それをファイルに書き込まずに標準出力（-cf -）へ流し、さらにそれを即座に解凍して標準出力（-O）に展開します。

4. 本来は「ネットワーク・転送」系

外部と通信するためのコマンドですが、「ローカルのファイルを自分自身に投げつける」ことで画面に表示させます。
• nc -l -p 12345 > /dev/null & sleep 1 && nc localhost 12345 < filename の変形
	• ネットキャット（nc）を使い、ローカルホストの空きポートに向けてファイルを転送し、それを画面で受け取る力技です。
• curl file://$(pwd)/filename
	• URLとして読み込む。 curl はウェブサイトのソースを表示するコマンドですが、プロトコルに file://（ローカルファイルスキーム）を指定すると、ただのファイル閲覧コマンドに変貌します。

5. 「コンパイル・ビルド」の過程で出す系

プログラマ向けのツールをあえて流用する方法です。
• gcc -E -x c filename
	• C言語のプリプロセッサ。 本来は #include などを展開するものですが、C言語のコードとして（-x c）テキストファイルを読み込ませると、マクロやコメント以外の地文（普通のテキスト）はそのまま出力されます（※行番号の注釈が入るので、完全に一致させるには grep などで削る必要があります）。
ターミナルのパイプやリダイレクトの仕組み、そして各コマンドの「デフォルトの挙動」をハックすると、いくらでも cat の代わりが作れてしまうのがLinuxの恐ろしくも面白いところです。
さらにニッチな領域として、「1文字もタイピングせずに（記号だけで）cat を再現する難解な技」や、「システムから cat のバイナリを削除された状態から復活させる方法」などはいかがですか？ご興味のある方向にさらに深掘りできます！
